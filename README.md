# Expense Tracker

A simple web-based expense tracker built using Python, Flask, HTML, CSS, and SQLite.

## Features

- Add and record expenses
- Store expenses in an SQLite database
- View and manage expense records
- Flask-based backend
- Simple HTML/CSS frontend

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
